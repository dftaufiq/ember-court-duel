Ember Court is an original duel card game that runs offline in a desktop browser: you and Sable, the Ash Herald, spend mana to play Flame, Tide, Thorn and Star cards, chain same-suit Resonance combos, and burn each other's Ember to zero.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click a card or press 1–7 to play it, Space to end the turn, R to restart, M to mute.
